# Нарек Погосян — личный сайт

Предприниматель, архитектор бизнес-систем. Одностраничный сайт-визитка:
статика без сборки и зависимостей.

**Развёртывание:** Cloudflare Workers, проект `remeslo`.

---

## Как это собрано и как разворачивается

Сборки нет. Cloudflare берёт содержимое `public/` и раздаёт как статику —
никакого скрипта-воркера в проекте нет.

```
wrangler.jsonc      конфиг: name, compatibility_date и папка с файлами
public/             то, что уезжает на Cloudflare
  index.html        весь текст сайта — правится здесь
  css/style.css     оформление
  css/fonts.css     объявления @font-face (собран скриптом)
  fonts/            18 файлов .woff2, ~300 КБ
  js/main.js        тема, счётчик листов, подсветка корешка
  img/              пусто — сюда класть фотографии
  robots.txt
```

Настройки проекта в панели Cloudflare:

| | |
|---|---|
| Команда сборки | нет |
| Команда развёртывания | `npx wrangler deploy` |
| Корневой каталог | `/` |

Новая сборка запускается пушем в `main`. Кнопка **Retry build** на самой
первой сборке не работает — она была создана импортом репозитория
(`seed_repo override`), а такие Cloudflare повторять не умеет. Это не
ошибка сайта: нужен новый деплой, а не повтор старого.

Локально:

```
npx wrangler deploy          # выкатить
npx wrangler dev             # посмотреть как на Cloudflare
python3 -m http.server -d public 8000   # просто открыть в браузере
```

## Идея оформления

Сайт собран как **лист рабочей документации**. Это не украшение ради
украшения: человек семнадцать лет сдаёт объекты по чертежам, и язык
чертежа — его собственный язык.

Отсюда всё остальное:

- **рамка листа** с угловыми засечками и координатными метками по краю;
- **штамп** в правом нижнем углу — как на чертеже. Он живой: показывает
  номер и название текущего листа, пока вы листаете. На узких экранах
  превращается в полосу по низу;
- **корешок** слева с номерами листов 01–09 — навигация по разделам;
- **размерные линии** (`|←— 17 лет в стройке —→|`) вместо декоративных
  разделителей;
- кейсы — не карточки, а **реестр объектов**: таблица с параметром, сроком
  и суммой, строки раскрываются;
- цифры — **ведомость показателей**, как в смете;
- миллиметровка на фоне, тонкие линейки, прямые углы.

Ограничения выдержаны намеренно: ни одной тени, ни одного скругления,
ни одного градиента, ни одного эмодзи. Один акцентный цвет — приглушённый
кирпичный. Всё остальное делает типографика и воздух.

### Цвет и шрифт

| | Светлая тема | Тёмная тема |
|---|---|---|
| Бумага | `#f4f1ea` тёплый бумажный | `#121110` антрацит |
| Текст | `#17140f` | `#efeae0` |
| Акцент | `#a4441c` кирпич | `#d2703f` |

Тема переключается в штампе и запоминается в браузере; по умолчанию
берётся системная.

- **IBM Plex Sans** — заголовки и названия объектов
- **IBM Plex Mono** — технические подписи, цифры, штамп
- **PT Serif** — длинные тексты и цитаты

Шрифты лежат в `public/fonts/` локально. Сторонних запросов страница
не делает вообще — ни шрифтов, ни аналитики, ни счётчиков. Подробности —
в [`public/fonts/README.md`](public/fonts/README.md).

### Язык и тема

Наверху справа — четыре кнопки: **Рус / Eng** и **День / Ночь**. Активный
пункт помечен цветом и подчёркиванием, выбор запоминается в браузере.

Тема по умолчанию берётся системная (`prefers-color-scheme`) и ставится
крошечным скриптом в `<head>` до первой отрисовки — иначе страница мигала
бы чужим цветом. Если пользователь выбрал тему руками, дальше следуем его
выбору; пока не выбрал — следим за системной и переключаемся вместе с ней.

Русский текст лежит прямо в `index.html` — он и показывается, если
JavaScript выключен. Английский подставляется из `js/i18n.js` по ключам
`data-i18n`. Русские строки в словаре **не дублируются**: при загрузке
оригиналы снимаются из DOM, и возврат на русский просто их восстанавливает.
Так словарь и разметка не могут разойтись.

Переводятся не только тексты, но и `<title>`, `meta description`, og-теги,
`alt` картинки, `aria-label` и даже буквы координатной сетки по краю листа
(кириллица меняется на латиницу). Язык можно задать адресом: `?lang=en`.

Добавить строку: повесьте `data-i18n="ключ"` на элемент и допишите ключ
в `EN` внутри `js/i18n.js`. Если ключа в словаре нет, английская версия
покажет русский текст — молча, без поломки.

## Разделы

| Лист | Раздел | Что внутри |
|---|---|---|
| 01 | Обложка | имя, дескриптор, три ключевые цифры |
| 02 | Позиция | кто, что делает, формула «понимание = ясность = система» |
| 03 | Ведомость | показатели и строка заказчиков |
| 04 | Метод | картирование проекта в 8 шагов, центробежные и центростремительные |
| 05 | Реестр объектов | 12 кейсов с цифрами, строки раскрываются |
| 06 | Экспертиза | четыре направления |
| 07 | Выступления | темы и форматы |
| 08 | Рамки | что здесь есть и чего здесь нет |
| 09 | Связь | шесть каналов |

Сайт полностью работает без JavaScript: без него не будет только
переключателя темы и живого счётчика листов, весь текст и раскрытие
строк реестра останутся на месте.

### Печать

Есть отдельные стили: на бумаге уходят рамка, штамп, корешок и кнопки,
фон становится белым, реестр печатается раскрытым (закрытые `<details>`
раскрываются на время печати скриптом — из CSS это надёжно не сделать),
а рядом с каждой ссылкой печатается её адрес.

## Что нужно доделать

**1. Домен.** Пока адрес сайта не зафиксирован, в `public/index.html`
нет `canonical` и `og:url` — они закомментированы вместе с подсказкой.
Неверный `canonical` хуже отсутствующего: он говорит поисковику, что
настоящая версия страницы живёт по другому адресу. Когда домен будет
известен, раскомментируйте эти две строки, подставьте его, допишите
строку `Sitemap:` в `public/robots.txt` и положите рядом `sitemap.xml`.

**2. Фотографии с объектов.** Портрет на обложке стоит
(`public/img/portret.jpg`, кадр 4:5, обесцвечен через CSS — файл лежит
цветным, `filter` в `.portrait img` снимается одной строкой). А вот кадров
со стройки ещё нет. Готовая разметка лежит закомментированной
в `index.html` (лист 02) — положите файл в `public/img/` и снимите
комментарий:

```html
<figure class="shot">
  <img src="img/portret-obj.jpg" alt="Нарек Погосян на объекте"
       width="1200" height="1500" loading="lazy" decoding="async">
  <figcaption>Подпись: объект, город, год</figcaption>
</figure>
```

Стили (`.shot`) уже написаны. Нужны реальные кадры со стройки, не сток.

**3. Обложка для соцсетей.** `og:image` не проставлен: картинки нет,
а ссылаться на несуществующий файл хуже, чем не ссылаться совсем.
Когда появится — положите `public/img/og-cover.jpg` (1200×630)
и добавьте в `<head>` вместе с адресом из пункта 1.

**4. Подписи к YouTube-каналам.** Каналов два, и подписаны они со слов
владельца: `@GK-REMESLO` — компания, `@gpt-remeslo` — ИИ и автоматизация.
Проверить содержимое каналов из рабочего окружения не удалось, так что
если подпись неточная — правится в листе 09.

## Проверено

- Ширины от 320 до 2560 px — горизонтальной прокрутки нет нигде,
  штамп ни на одной ширине не перекрывает колонку с суммами.
- Контраст всего текста — не ниже 4.5:1 (WCAG AA) в обеих темах.
- Все символы страницы покрыты подключёнными подмножествами шрифтов,
  включая `₽`, `→` и `≈`.
- Все файлы отдаются из `public/` по относительным путям.
- Клавиатурная навигация, `prefers-reduced-motion`, `prefers-color-scheme`.
