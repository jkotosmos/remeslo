# Yunnan Tea — оптовый прайс 2026

Одностраничный сайт-каталог юньнаньского чая на трёх языках (русский, английский,
китайский). Статика без сборки и зависимостей: открывается как обычный `index.html`,
разворачивается на GitHub Pages как есть.

**Демо:** https://jkotosmos.github.io/tea/

## Что внутри

```
index.html          вёрстка и мета-теги
css/style.css       оформление, светлая и тёмная темы
js/data.js          каталог, собран скриптом из 2026年茶叶价格表.xlsx
js/i18n.js          словари ru / en / zh
js/app.js           язык, фильтры, поиск, микроразметка
img/                29 снимков, по 4 файла на каждый (JPEG + WebP × 2 размера)
tools/              генератор каталога и сверка подписей со словарём
CREDITS.md          источники и лицензии фотографий
```

### Подписи в разметке

Тексты в `index.html` продублированы статически — их видят соцсети при построении
карточки ссылки и краулеры, не выполняющие JS. Когда правите `js/i18n.js`, эти
дубли молча расходятся со словарём, поэтому есть сверка:

```bash
python tools/sync_fallbacks.py           # показать расхождения
python tools/sync_fallbacks.py --write   # подтянуть из русского словаря
```

## Данные

Каталог собран из файла `2026年茶叶价格表.xlsx` скриптом — цифры не набирались руками.

* 45 позиций, 17 садов, 2 фабрики (Бабянь и Мэнмэнь);
* цена за килограмм маочи в юанях по прайсу 2026 года;
* три сезона сбора: весна, лето (−30 % к весне), осень (−15 %);
* у двух позиций цены 2026 года в файле нет — они показаны как «цена по запросу»
  с указанием года последней котировки, а не выдуманным числом.

### Наценка

Цены прайса выводятся на сайт с наценкой **+15 %**. Она задана одной константой —
в генераторе `tools/gen_data.py`, откуда попадает в `js/data.js`:

```js
// js/data.js — строка генерируется, править надо MARKUP в tools/gen_data.py
const MARKUP = 1.15;
```

Одно и то же округлённое значение уходит и в вёрстку, и в микроразметку
`schema.org/Offer`, поэтому расхождений между витриной и выдачей не бывает.

### Валюта

Прайс юаневый, но над каталогом стоит переключатель ₽ / ¥. Русскому интерфейсу по
умолчанию показываются рубли, английскому и китайскому — юани; выбор запоминается
в `localStorage`.

Курс зашит в код, потому что страница не делает ни одного внешнего запроса
(`connect-src 'none'`), а тянуть его онлайн — значит ломать это свойство ради
цифры, которая всё равно справочная:

```js
// js/app.js
const RUB_PER_CNY  = 12.1655;      // курс ЦБ РФ
const RUB_RATE_DATE = '2026-08-08';
```

**Курс надо обновлять руками.** Дата из `RUB_RATE_DATE` печатается в сноске под
каталогом, так что устаревший курс виден посетителю, а не прячется. Рублёвые суммы
везде идут со знаком «≈», а в микроразметке `schema.org/Offer` цена всегда юаневая:
курс к моменту индексации успеет измениться.

### Пересборка каталога из нового прайса

`js/data.js` собирается скриптом `gen_data.py` (он читает лист и раскладывает
строки по садам и сезонам). Если фабрики пришлют новый файл, замените исходник и
перегенерируйте `data.js` — вёрстку и словари трогать не нужно.

## Что нужно заменить перед публикацией

| Где | Что |
|---|---|
| `js/app.js` → `CONTACT` | телефон/WhatsApp, Telegram, почта |
| `js/app.js` → `RUB_PER_CNY`, `RUB_RATE_DATE` | актуальный курс ЦБ и его дата |
| `js/app.js` → `SITE` и `index.html` | домен, если он не `jkotosmos.github.io/tea/` |
| `js/i18n.js` → `log_b1…log_b4`, `a6`, `a7` | реальные условия поставки, минимальная партия, сроки |

Раздел «Поставка» намеренно написан без конкретных цифр: сроков, минимальных
партий и тарифов в исходном прайсе нет, а придумывать их для коммерческого сайта
нельзя.

## Языки

Язык определяется в таком порядке: параметр `?lang=`, затем `localStorage`, затем
язык браузера. Переключатель в шапке меняет тексты, мета-теги, `og:locale`,
форматирование цен и микроразметку без перезагрузки страницы.

Поиск в каталоге работает по всем трём языкам сразу: «Хуэйта», `Huita` и 会塔
находят одну и ту же позицию независимо от выбранного интерфейса.

## Безопасность

* `Content-Security-Policy` в `<meta>`: только собственные ресурсы, `connect-src 'none'`,
  `object-src 'none'`, `form-action 'none'`;
* ни одного стороннего скрипта, шрифта, счётчика или пикселя — проверяется тем, что
  вкладка не делает ни одного внешнего запроса;
* весь динамический вывод экранируется (`esc()`), обработчиков в атрибутах нет;
* внешние ссылки — с `rel="noopener noreferrer"`.

`frame-ancestors` в `<meta>` браузеры игнорируют. При переезде с GitHub Pages
продублируйте политику HTTP-заголовком на стороне сервера.

## Доступность и мобильные

Проверено при 375 px: горизонтальной прокрутки нет, сетка в одну колонку, меню
сворачивается в бургер, снизу появляется панель с призывом к действию. Контраст
текста проходит WCAG AA в обеих темах; цели нажатия — не мельче 36 px;
анимации отключаются при `prefers-reduced-motion`.

## Локальный запуск

```bash
python -m http.server 8744 --directory .
```

Затем откройте http://localhost:8744. Сборка не нужна: файлы отдаются как есть.
