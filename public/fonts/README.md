# Шрифты

Все три семейства лежат локально — страница не делает ни одного запроса
к сторонним серверам.

| Семейство | Автор | Где используется |
|---|---|---|
| IBM Plex Sans | IBM | заголовки, имена объектов, интерфейсные подписи |
| IBM Plex Mono | IBM | технические подписи, цифры, штамп, ведомости |
| PT Serif | ParaType | длинные тексты, лид-абзацы, цитаты |

Все три распространяются по **SIL Open Font License 1.1**.
Полный текст лицензии — в `OFL-IBM-Plex.txt` (тот же текст лицензии
относится и к PT Serif; правообладатель PT Serif — ParaType, 2010).

## Как собраны файлы

Взяты подмножества `cyrillic` и `latin` плюс отдельное микро-подмножество
с символами `₽`, `→` и `≈` — их нет ни в кириллическом, ни в латинском
наборе Google Fonts, и без него браузер подставлял бы системный шрифт.

IBM Plex Sans — переменный шрифт: один файл на подмножество,
`font-weight: 400 600`. IBM Plex Mono и PT Serif — статические начертания,
по файлу на каждое.

Объявления `@font-face` лежат в `../css/fonts.css`. Этот файл собран
скриптом — если понадобится добавить начертание, проще перегенерировать
его целиком, чем править руками.
